# 护盾 UI 图集

`ShieldBarAtlas.png` 是 64×64 RGBA 透明图集。主体使用灰白遮罩，运行时染为蓝青、金色或琥珀色，不在贴图中写数字或文字。

| 区域 | 源矩形 `(x, y, width, height)` | 用途 | 固定端宽 |
| --- | --- | --- | --- |
| Frame | `(0, 0, 32, 16)` | 一像素圆角轮廓 | 5 |
| Track | `(0, 20, 32, 12)` | 深色底槽遮罩 | 3 |
| Fill | `(0, 36, 32, 12)` | 纵向渐变填充 | 3 |
| Glow | `(40, 0, 16, 32)` | 柔和端点光晕 | 不分片 |

`ShieldBarRenderer` 将左右端保持固定宽度，中段横向拉伸。蓝金区段裁剪同一条完整填充形状，不在交界处重新生成圆角；整次绘制不改变 SpriteBatch 状态或添加 shader。

替换约定：

- 保持图集尺寸、矩形位置和间隔；变更布局时一起修改渲染器常量。
- Frame 保持内部透明、轮廓细；Track 和 Fill 保持可染色的灰白渐变。
- Glow 的透明度应平滑降至边缘，避免硬边或高亮白块。
- 图集之外的区域保持透明，防止缩放时相邻区域串色。
- 运行路径为 `TestMod/Assets/Textures/UI/ShieldBarAtlas`；纹理由客户端资源系统管理，卸载时只清理 Asset 引用，不手动 Dispose 共享纹理。
