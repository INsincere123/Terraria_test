# 旅人归途暗处遮盖免疫

- 完整终极套装和神之心各自激活 `TheDarkImmunityEffect`；每玩家标志每帧重置，双来源只处理一次。龙/炮台开关不影响该效果。
- 可选反射接入 `ContinentOfJourney.TemplatePlayer.theDarkDrawTimer`，只缓存模板和成员，每次取得当前玩家的实例。装备结算在旅人归途 `PostUpdateBuffs` 的计时处理之后，每帧维持值 60。
- 不设置 `HomingBeacon`、不添加 Buff、不改环境判定；无新增物块扫描、光源或整屏补光。保留迷宫机关、碰撞与战斗机制。正常无光处仍需光源。
- 卸装后停止覆盖计时，遮盖按旅人归途自己的计时渐变恢复；仍处于归航灯塔/火把效果中时继续遵循其原规则。
- 未加载旅人归途或成员解析失败时不激活、不显示提示；失败记录一次警告并停用兼容。卸载清空缓存，无新增钩子或持久数据。
