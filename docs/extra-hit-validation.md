# 额外伤害统一结算与验证

## 结算约定

`ExtraHitEffect.Compute` 共用于直接结算和弹幕投送，公式为：

```text
完整玩家增伤.ApplyTo(固定伤害 + 玩家属性 × 属性比例)
    + 实际命中伤害 × 命中比例
```

没有固定/属性部分时，不调用 `ApplyTo(0)`，避免玩家平伤混入纯比例效果。两部分合并后向下取整，最低 1 点。`Compute` 的返回值已经包含一次玩家增伤，调用方不能再增伤。

| 效果 | 增伤规则 | 独立暴击 | 投送方式 |
| --- | --- | --- | --- |
| 心之钢 | `(240 + 最大生命 × 0.88)` 吃一次完整增伤 | 按当前手持武器类型的 `GetTotalCritChance`，含 Generic 继承；不额外叠加物品自身暴击 | `Strike` |
| 狂暴之刃 | 固定 100 吃真实伤害完整增伤，实际命中伤害的 17% 不重复增伤 | 禁止 | `Strike` |
| 专注宝珠 | 已暴击的实际命中伤害 × 2，不再次增伤 | 禁止；“本该暴击”仍是触发条件 | `Strike` |
| 副手/Antares 炮台 | 实际命中伤害 × 0.19 | 禁止，清除父弹幕暴击快照 | `SpawnProjectile` |
| 幻影弓、破晓、星尘龙溅射 | 实际命中伤害 × 原有比例 | 禁止 | `StrikeRatio` |
| 鞭标记爆炸 | 实际命中伤害 × 注册表中的爆炸比例 | 禁止 | `SpawnProjectile` |
| 暗印收割 | 基础 66 吃一次 Generic 完整增伤 | 禁止 | `Strike` |

暴击率通过 `GetTotalCritChance` 读取；`UseCrit` 默认为 false。启用它会独立判定整次额外伤害，当前比例/混合效果均保持 false。心之钢不读取原攻击的 `hit.Crit`，也不消耗专注的强制暴击额度。

目标的防御、抗性和 NPC 通用命中修正仍正常结算。实际命中比例部分免于再次应用**玩家增伤和暴击**，不是绕过新目标的防御/抗性。真实伤害通过 `GlobalNPC.Damage.ModifyIncomingHit` 无视防御，仍保留抗性；也可用 `IgnoreDefense` 明确配置。统一额外伤害不会再掷一次弹幕随机伤害浮动。

直接路径不分发物品/弹幕的普通 OnHit 回调。追加弹幕用每实体 `IsExtraHit` 标记阻止本模组的追加攻击、专注额度消耗、狂暴叠层、心之钢触发、鞭爆炸和暗印收割；原有弹幕吸血/命中 debuff 行为保留。标记、暴击开关、穿防开关、伤害类型与副手数字标记随 ExtraAI 同步。直接伤害的 `NoPlayerInteraction` 仅控制单机玩家归属登记，不控制 OnHit 分发或伤害包发送。

普通武器、召唤物主攻击、冲刺碰撞及世界祭坛脉冲不属于本次追加伤害迁移。既有攻击比例、目标选择、范围、冷却、owner/netMode 触发边界和表现保持各自原有逻辑；原版磁球武器不会获得追加弹幕标记。

## 已执行的源码与隔离检查（2026-10-05）

- 按实际 `TestMod.csproj -> ../tModLoader.targets -> Steam tMLMod.targets` 导入链执行 `ResolveReferences;CoreCompile`，通过。
- 本机安装 API 为三参数 `NPC.StrikeNPC(HitInfo, bool, bool)`；实现使用本机签名，未照搬参考树中的 owner 参数。
- 临时 C# 检查项目链接实际 `ExtraHitEffect.cs`，使用 Terraria/XNA 替身，共通过 28 项断言：固定/属性增伤一次、纯比例不读取玩家增伤（含平伤）、混合部分分离、0%/100%及阈值暴击、强制暴击禁止、无二次随机浮动、弹幕数值/归属标记、无视防御配置、无归属登记时仍发送联机伤害包、单机无伤害包、原版数字保留和无效目标保护。

## 待游戏内验证

1. Build + Reload 后对非木桩敌人验证副手和 Antares 炮台；木桩被追加攻击分发主动排除。
2. 心之钢分别在低暴击率和完整暴击率达到 100% 时触发，确认独立暴击、当前手持武器职业切换和实际伤害对应的永久生命叠层。
3. 狂暴之刃满层与专注主动期间切换增伤装备，确认比例部分只随原命中变化，额外伤害不再次暴击。
4. 副手同时启用专注，确认磁球追加射弹命中不减少剩余强制暴击次数，不触发心之钢、再次发射副手或生成鞭爆炸。
5. 高防御/有抗性的目标上确认普通追加伤害和真实伤害的差异；尤其检查新目标溅射和副手弹幕，百分比并不承诺扣血后仍精确等于原命中比例。
6. 两名玩家、服务器及两个客户端同时装备副手/专注/心之钢，确认一颗追加弹幕、一次伤害包、正确归属及不重复的战斗数字。现有 server/client 触发边界需要实测。
7. 可选文本模组启用和缺失时分别确认数字；普通磁球武器仍使用原有攻击和暴击路径。
