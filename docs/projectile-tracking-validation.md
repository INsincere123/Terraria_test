# 弹幕追踪优化验证

## 实现范围

- `ProjectileTargetCache` 是每弹幕实例的局部缓存，不持有静态 NPC 列表。普通追踪每 6 个游戏帧重选最近目标，空场同样限频；目标失效、出范围、类型变化或 NPC 实例被同类型新实体替换时立即重选。每次查询实时核对可追踪性和位置。
- 通用高阶追踪、破晓、乌鸦、蜘蛛、原版冲撞型召唤物、AntaresBeam、幻影强化箭、血饲匕首和强制追踪已接入。类星体碎片保留发射时 `ai[0] = whoAmI + 1` 的指定目标及 1.35 倍保留范围，备用目标使用缓存。
- 星尘龙头和沙漠虎在完整 7200px 范围内锁定普通目标 45 个游戏帧，避免目标超过 900px 后逐更新重扫；空场每 6 帧重试。
- 召唤物追踪优先响应范围内的玩家右键指定目标。普通武器射弹不使用召唤物指定目标。
- `GlobalProjectile.Tracking.cs` 在本次最终速度确定后进行 owner 同步检查：目标变化立即请求；累计转向 10 度或速度变化达到 max(2, 上次速度的 10%) 时，至少间隔 3 个游戏帧；有目标时最长间隔 15 帧。无目标不周期同步，不清除其他钩子的 `netUpdate`。
- 强制追踪次数仅由 owner 消耗，标记通过压缩 bit 同步；插值转向后恢复原速大小，目标重叠或速度为零时不改速度。未启用 GodMode 也能进入强制追踪；破晓插入敌人后继续排除转向。
- 乌鸦防聚堆使用现有 owner/type 弹幕索引，随机传送由 owner 决定，并同步冲刺周期 `localAI[0]`；蜘蛛和冲撞型召唤物的随机返回位置同样由 owner 决定。
- AntaresBeam、幻影强化箭、血饲匕首的速度保底使用安全归一化；命中后请求同步停追冷却。此前两批优化保留速度参数，本次小幅增强见下表；伤害、穿透及现有起飞/停追时长保持原值。注释统一区分游戏帧和 AI 更新次数；星云烈焰沿用实际 2400px 范围。
- 第二批：Antares 本体、黑洞本体、雷之剑士和幻影龙头接入各自实例缓存，不增加定期同步请求。Antares 普通目标实时保留原 `Collision.CanHit(..., 0, 0, ..., 0, 0)` 视线判断，右键指定目标仍可穿墙；黑洞指定范围包含 1.5 倍边界，雷之剑士指定范围仍严格小于 2 倍，幻影龙仍以玩家中心选最近目标。
- 两侧类星体喷流复用父黑洞的目标缓存，不再独立完整搜索 NPC；每次访问仍核对父实体、目标状态和距离。雷之剑士只在跟随阶段搜索目标，冲刺继续使用原 `ai[2]` 目标，恢复不搜索；环绕排位及全体冲刺使用 owner/type 弹幕索引，保持槽位遍历顺序。
- 仅用于距离阈值比较的雷之剑士、幻影龙脱战范围、蜘蛛/冲撞型返回范围及黑洞返回/限速检查改用平方距离，阈值与状态机保持原值。
- 本体追踪排除名单新增泰拉棱镜 `EmpressBlade` 和阿比盖尔 `AbigailMinion`：名单优先于 PostAI 专属/通用追踪；泰拉棱镜不再叠加高阶追踪，阿比盖尔不再归入蜘蛛，因此不扩展追击/返回范围、不修改独立无敌帧、不命中弹开。两者保留原版本体 AI，GodMode 等独立伤害强化及物品数值不属于本次排除范围。

## 两种龙头自然追踪

- `DragonFlightController` 是每龙头独立的内部状态，分为追击、穿行、回转。速度大小与方向分别控制，预测在距碰撞边界 160px 内逐渐消退；接触目标后沿原方向穿过，在目标外累计 30% 龙链长度的余量（70～150px），最长 12 个游戏帧，然后沿弧线回转。回转朝向误差小于 30° 时回到追击。
- 星尘龙在普通模式及 GodMode 下均接管头部攻击：PreAI 保存入射速度，原版 AI 继续管理存活、返回、缩放、淡入和龙链，PostAI 从入射速度计算新运动并更新贴图朝向。命中后 3 次 AI 更新停追同样不依赖 GodMode，期间仍累计穿行距离和时间；切换 GodMode 不清理攻击阶段。GodMode 的既有 ×8 伤害倍率及溅射强化保留原边界和数值；沙漠虎仍使用原追踪函数。
- 幻影龙仍以玩家中心索敌、保留闲置悬浮和 13 节龙链。移除周期性 145px 目标偏移、单次增减 16 的速度变化和 320px 内停止转向的分支；身体跟随、头部统一绘制、伤害段、伤害倍率和独立无敌帧不变。旧公开攻击常量保留源级兼容，新攻击运动统一读取 `DragonFlightSettings.Phantom`。

| 每游戏帧参数 | 星尘龙 | 幻影龙 |
| --- | --- | --- |
| 正常攻击速度 | clamp(42 + 中心距离 / 30, 42, 150) | clamp(22 + 中心距离 / 30, 22, 46) |
| 最大加速 / 减速量 | 4 / 6 | 1.5 / 2 |
| 远处 / 近处转向上限（弧度） | 0.14 / 0.28 | 0.12 / 0.24 |
| 加强转向上限（弧度） | 0.55 | 0.40 |
| 调头临时速度下限 | 16 | 14 |
| 预测时间上限 / 倍率 | 12 / 0.65 | 8 / 0.5 |

- 远近转向以碰撞边界距离 160～600px 平滑插值，转向上限自身使用每帧 0.2 平滑。朝向误差超过 60° 时，限制目标速度为转向上限乘合计碰撞半径的 80%，再按临时下限钳制；速度仍受加减速上限约束。连续 30 个游戏帧无接近进展时加强转向，恢复进展或接触时退出，不直接瞬转或攻击传送。
- 速度在控制器内部按游戏帧换算，输出仍为每 AI 更新位移；加减速、角速度和阶段计时按 `1 / MaxUpdates` 分摊。1/3 步长累计使用小容差避免延后一更新。
- owner 选择目标及阶段，远端只预测收到的状态。两种龙头 ExtraAI 负载包含启用状态、目标槽位/类型、阶段、穿行方向/余量/时间、平滑转向上限、回转方向及无进展状态；星尘龙额外同步 0～3 次命中停追计数。无效槽位、死亡/类型变化、同类型 NPC 实例替换、非有限/越界状态退回非攻击状态。
- 目标或阶段改变请求同步，持续运动沿用 3/15 帧节流；幻影龙身体不附带运动控制器负载。目标失效、脱战、原返回传送和死亡清理状态；GodMode 关闭不再清理星尘龙状态。
- 本轮前的当前工作树源码及旧检查程序独立保存于 `obj/dragon-flight-baseline/20261004-231910/`；基线包含已有未提交改动，不使用 Git HEAD 代替。本轮源码未提交。

## 待游戏内验证

1. **加载与热重载**：tModLoader -> Mod Sources -> Build + Reload；切世界、重召唤，确认无异常和旧目标残留。
2. **聚焦球**：未开启 GodMode 时，用普通武器、星云烈焰和破晓分别发射，确认只消耗符合条件的物品直发弹幕，远端也持续转向；破晓插入敌人后不被追踪拉动。
3. **目标规则**：至少两个敌人，测试右键切换、取消、目标死亡/变为不可追踪、出范围；武器射弹仍追最近敌人，召唤物及时响应指定目标。
4. **远距离追击**：普通模式及 GodMode 下分别测试星尘龙头、沙漠虎追击 900px 外目标；观察锁定稳定性、失效重选及无目标返回。
5. **专用射弹**：AntaresBeam、幻影强化箭和血饲匕首反向转弯时不消失或出现异常速度，起飞和命中停追保持原手感；类星体碎片的原目标死亡后能稳定追击备用目标。
6. **双客户端**：双方同时召唤乌鸦、蜘蛛和冲撞型召唤物，测试冲刺、随机传送、超距离返回和标记射弹；比较 owner、服务器及旁观端的轨迹、碰撞和特效。
7. **性能对比**：相同地图、敌人和弹幕数量，分别记录空场与战斗的完整 NPC 搜索次数、每秒实际 SyncProjectile 包数和更新耗时。请求同步次数与实际发包次数分开记录，不能用静态扫描减少比例推导帧率。
8. **第二批场景**：Antares 普通目标被墙挡住时立即停止选它，右键指定目标仍可穿墙；黑洞和成对喷流响应同一指定目标及其死亡；雷之剑士重召后环绕排位正确、满蓄力仍只触发一次全体冲刺、恢复结束才重新寻敌；幻影龙头保持以玩家中心索敌和原攻击轨迹。
9. **增强手感**：比较静止目标、横向高速目标、近距离转弯及命中后再次追踪，确认更快接近/对准目标，无明显绕圈或抖动；双客户端观察更快转向后的轨迹纠正和目标切换。以上场景尚未在游戏内执行。
10. **龙头自然追踪**：分别测试静止小怪、大体积 Boss、高速移动 Boss；星尘龙测试长短龙链及 GodMode 开关，确认普通模式已追踪、切换不重置穿行/回转和命中停追。幻影龙检查身体跟随、无目标返回、玩家死亡与重召。双客户端比较指定目标、阶段切换、停追及连续回转，确认无明显急折、长时间绕空圈或龙身断裂。
11. **本体追踪排除**：Build + Reload 后重新召唤泰拉棱镜和阿比盖尔，分别测试普通模式、GodMode、远距离目标和命中，确认保留原版 AI/无敌帧、不额外弹开；现存阿比盖尔可能仍有先前 SetDefaults 写入的无敌帧设置，须重召验证。三种蜘蛛仍保留原增强。此项尚未游戏内验证。
