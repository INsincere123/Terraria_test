# 终极盔甲效果开关

## 使用与状态

- 三件物品及其纹理位于 `Content/Items/Armor/UltimateArmor/`，物品类型为 `UltimateHelmet`、`UltimateBreastplate` 和 `UltimateLeggings`，显示名称分别为终极头盔、终极胸甲和终极腿甲。
- 三件物品使用 `LegacyName` 映射原有内部物品名，供旧存档解析；胸甲与腿甲继续使用原有 `effectEnabled` 保存字段。
- 背包中 Shift＋右键胸甲切换幻影龙，Shift＋右键腿甲切换套装炮台，不消耗物品。
- 两个开关默认开启，随每件物品分别保存和同步；旧存档缺少 `effectEnabled` 字段时默认开启。
- 开关控制完整套装来源。单独装备胸甲或腿甲不会启用对应效果；基础属性、复活和引力井不受开关影响。
- 物品右下角使用原版 `Extra_20` 的启用/禁用帧，tooltip 和套装说明显示对应状态。
- 关闭后停止维持既有幻影龙或炮台，沿其原有短生命周期自然消失。已射出的炮台子弹不清除；副手饰品可以独立维持并触发同一个炮台。

## 双幻影龙

- 胸甲开关同时维持两条独立幻影龙，每条7节、6个间距；节点间距仍为25.5像素，链长153像素，是原13节链长306像素的一半，贴图和碰撞体积不缩小。
- 每条龙的可伤害节点基础伤害为550，击退4.6、命中冷却15帧保持原值；头部及段号为4的倍数的身体造成接触伤害。两条短龙共有4个伤害节点，不补偿相较原单龙3个1100伤害节点的总输出变化。
- 幻影龙节点使用项目的 `TrueDamageClass`，由现有全局命中钩子处理忽略防御及真实伤害文字；单龙接口也使用同一节点类型。
- 原色链右侧生成与悬停，反色链左侧生成与悬停，各自选目标并执行原有飞行控制；第二条的头、身、尾和连接补绘均使用保留透明度的RGB反色纹理。
- 索敌周期为4个游戏帧，首次查询和目标失效立即重选；索敌半径80格（玩家中心）、脱战距离115格（玩家中心）、强制回位距离130格（各链悬停点）。
- 追敌速度参数从22～46提高至25～52像素/游戏帧，加速度从1.5提高至1.7；保留原有转向、刹车和近身回转减速规则，实际回转速度可以低于该追敌速度区间。
- `ai[2]` 为链编号：0保留13节单龙接口，1为7节原色链，2为7节反色链；owner和链编号共同隔离查询、重建、跟随和绘制。只有owner能创建或重建链。
- 反色纹理在客户端首次绘制时生成并缓存，按预乘alpha计算 `RGB' = A - RGB`，卸载时在图形主线程释放；不会修改源PNG或切换SpriteBatch。
