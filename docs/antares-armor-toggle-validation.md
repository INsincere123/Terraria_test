# Antares 盔甲效果开关

## 使用与状态

- 背包中 Shift＋右键胸甲切换幻影龙，Shift＋右键腿甲切换套装炮台，不消耗物品。
- 两个开关默认开启，随每件物品分别保存和同步；旧存档缺少 `effectEnabled` 字段时默认开启。
- 开关控制完整套装来源。单独装备胸甲或腿甲不会启用对应效果；基础属性、复活和引力井不受开关影响。
- 物品右下角使用原版 `Extra_20` 的启用/禁用帧，tooltip 和套装说明显示对应状态。
- 关闭后停止维持既有幻影龙或炮台，沿其原有短生命周期自然消失。已射出的炮台子弹不清除；副手饰品可以独立维持并触发同一个炮台。
