# 血饲匕首修复与验证

## 结算和生命周期

- 正常阶段每发匕首在扣血后、检查暴走前，将失血伤害倍率和附加暴击率记录到 `ai[1]`、`ai[2]`。触发暴走的本发以及此前飞出的匕首保留各自的发射快照。
- `Shoot` 传入的伤害已包含引擎计算的玩家增伤。暴走和虚弱阶段不再叠加正常阶段倍率或暴击；引擎继承武器/玩家暴击后，只在 `OnSpawn` 补入正常阶段附加暴击。总暴击率通过弹幕 ExtraAI 同步。
- 治疗量查询只负责虚弱期恢复翻倍。真实治疗物品消耗通过 `GlobalItem.OnConsumeItem` 清除 debuff，保留虚弱本身；悬停 tooltip 和快速治疗选药不净化。
- 暴走临时保存每颗弹幕的剩余穿透与最大穿透。结束暴走、owner 死亡/失活、owner 无效或弹幕变成敌对时撤销无限值；原生无限穿透不接管，其他 AI 已设置的有限值不覆盖。快照和接管标志通过 GlobalProjectile ExtraAI 同步。
- 死亡和进入世界清理阶段历史、衰减基准和扣血计数。自然到期仍进入 600 帧虚弱；死亡后复活不误触发虚弱。
- 伤害曲线、扣血数值、暴走和虚弱时长保持原值。

## 待游戏内验证

1. Build + Reload 后，在虚弱期携带多个 debuff，悬停治疗药水并让快速治疗选药；未实际消耗时 debuff 保留。分别普通用药和快速治疗，恢复翻倍且净化，虚弱保留。
2. 在 20% 生命边界附近投掷匕首，确认触发暴走的本发保留扣血后加成。用伤害浮动和暴击区分实际命中数值，不把单次数字当成精确倍率证明。
3. 普通匕首飞出后触发暴走、进入虚弱或恢复生命，确认这些在途匕首保留发射时倍率和暴击；暴走/虚弱期间新发射的匕首只吃一次通用加成。
4. 使用有限穿透且寿命超过暴走剩余时间的弹幕，暴走期间确认无限穿透，结束后恢复进入暴走时的剩余次数与最大次数；原生无限穿透仍无限。
5. 暴走中死亡并复活，确认没有额外 10 秒虚弱；存活到自然结束时仍正常附加虚弱。退出/进入世界后确认扣血计数和阶段历史不残留。
6. 两名玩家、服务器及两个客户端验证同一发射弹、实际暴击和临时穿透同步；另一名玩家未暴走时不受影响，暴走结束或 owner 死亡后双方穿透表现一致。
